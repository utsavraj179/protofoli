# MOWAZ.EXE - 3D Developer Portfolio

React 19, Vite, Three.js (React Three Fiber + Drei), Tailwind CSS and Framer Motion.

## Features
- Interactive 3D retro PC in the hero (orbit rotation)
- Draggable 3D tech balls with labels
- Rotating 3D planet in the contact section
- 5,000-star procedural starfield
- Tilt cards for disciplines and projects
- Experience timeline, contact form (opens your mail app), copy-email and Discord invite
- All 3D is procedural, so there are no model files to host

## Setup
```
npm install --legacy-peer-deps
npm run dev
npm run build
```

## Customize
Edit `src/constants/index.js` (name, links, projects, experience, tech).

## Deploy to Vercel
Framework: Vite, build command `npm run build`, output `dist`.
